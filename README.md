# Rubrix

**Rubrica contatti per sistemi Unix-like**

Rubrix è una semplice applicazione da terminale, scritta in linguaggio C, per la gestione di una rubrica telefonica.

Il progetto nasce da un'esigenza personale e rappresenta anche un'occasione di studio e sperimentazione del linguaggio C.

## Caratteristiche

- Inserimento di nuovi contatti
- Visualizzazione dell'elenco dei contatti
- Ricerca e visualizzazione dei singoli contatti
- Modifica e cancellazione
- Ordinamento della rubrica
- Gestione degli archivi
- Esportazione dei dati

## Versioni

- **Versione 0:** prima versione del programma.
- **Versione 1.0:** riorganizzazione del codice, introduzione della gestione degli archivi e ampliamento delle funzionalità.

## Requisiti

- Sistema operativo Linux o Unix-like
- Compilatore GCC

## Compilazione

Per la compilazione di Rubrix occorre avere installato sulla popria distribuzione GNU/Linux il GNU GCC Compiler.
Aprire in ambiente Linux un terminale con la combinazione di tasti CTR-ALT-C e digitare nella directory in cui il sorgente è salvato:
[gcc -Wall -Wextra -g rubrix.c -o rubrix]

## Esecuzione

Terminata la compilazione, digitare la seguente riga di comando:
[./rubrix]
